# What the field already knows, and what this folder can therefore claim

Searched 2026-08-16, before committing four more hours of machine time, and it
changed the framing rather than the design. Recorded because the alternative is
writing up an established result as a discovery.

The short version: **most of this grid is a replication, and the part that is
not is one cell of it.** Cheap talk raising cooperation is established, prompt
wording moving the outcome is established, seating language models beside
canonical strategies is published, and injecting a synthetic *cooperative*
history has a close relative in the literature. What was not found done is the
**defective** mirror of that injection, crossed with the channel, measured
against a mechanism that provably cannot escape.
